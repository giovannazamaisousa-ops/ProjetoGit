# tutorialzinho prático

antes de tudo, aperte a tecla Windows ou no símbolo do Windows no cantinho inferior esquerdo da tela e pesquise por Windows PowerShell (é la que será feito)

para criar sua pasta..
cd desktop,
mkdir   ProjetoGit

para entrar na pasta..
cd ProjetoGit

para se identificar..
git config --global user .name "Seu nomezinho",
git config --global user .email "seu e-mail aqui"

feito isso, agora inicie o git..
git init

para comitar..
git commit -m "faça seu commit(alteração)"

para adicionar..
git add .

para limpar o que você está fazendo quando tiver muitas informações, coloque cls (não apaga o que foi feito apenas limpa)
